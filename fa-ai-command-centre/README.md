# F&A AI Command Centre

A local React + Vite executive dashboard for the Telkom/WNS F&A Executive Business Review, including Chart.js visuals, AI adoption radar, roadmap intensity bar, transformation portfolio cards and risk/control views.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown in the terminal, usually:

```text
http://localhost:5173
```

## Build for sharing

```bash
npm run build
npm run preview
```

## Colour palette

The styling uses a Telkom-inspired palette:

- Telkom blue: `#0072CE`
- Deep blue: `#003B71`
- Cyan: `#00AEEF`
- Yellow: `#FFD200`
- Lime: `#A6CE39`

You can edit these in `src/main.jsx` and `src/styles.css`.
